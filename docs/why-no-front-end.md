# Why there is no front end

This build is for the internal caseworker who asks which applications need attention, records a human review and prepares the next brief. Those jobs work from a database and command recipes without a visual application.

Salesforce Benefit Management also provides constituent journeys, guided flows and connections to benefit delivery. This free build replaces the internal application register and evidence-review workflow. It is not a feature-for-feature copy of that platform.

A screen gives applicants an intake form, mobile uploads and status tracking. Offline field work, drag and drop, authenticated shared editing and a constituent portal need additional software. None is required for a trusted internal operator working from exported records. Enterprise DNA builds the agreed screens and connections into a custom version.

Read-only HTML reports and printable briefs are views of the records. They have no controls that change data and no running server. Run the CLI to act. Keep reports under the same access restrictions as the database.

Use the controlled document store for identity records. Keep final eligibility decisions, statutory notices, disbursement approval and payment execution with the authorised organisation and its existing processes.
